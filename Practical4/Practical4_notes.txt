The main driver program provides an interactive, menu-driven interface to explore:
1. Linked List operations (InsertFirst, InsertLast, RemoveFirst, RemoveLast, PeekFirst, PeekLast, Display)
2. Stack operations backed by Linked List (Push, Pop, Top, Display)
3. Queue operations backed by Linked List (Enqueue, Dequeue, Peek, Display)


ACTIVITY 1: DSALinkedList (Doubly-Linked, Double-Ended)
- Node class: DSAListNode storing value, next, and prev pointers.
- List class: DSALinkedList maintaining head and tail pointers.
- Operations:
  * insertFirst(value): O(1) time
  * insertLast(value): O(1) time
  * peekFirst(): O(1) time
  * peekLast(): O(1) time
  * removeFirst(): O(1) time
  * removeLast(): O(1) time
- Edge cases handled:
  * Empty list: raises IndexError on remove/peek.
  * Single-item list: resets head and tail to None on removal.
  * Multi-item list: preserves forward and backward pointer links.


ACTIVITY 2: DSAStack & DSAQueue using DSALinkedList
- DSAStack:
  * push(value) -> calls insertFirst(value) (O(1))
  * pop() -> calls removeFirst() (O(1))
  * top() / peek() -> calls peekFirst() (O(1))
  * isEmpty() -> calls isEmpty() (O(1))
- DSAQueue:
  * enqueue(value) -> calls insertLast(value) (O(1))
  * dequeue() -> calls removeFirst() (O(1))
  * peek() -> calls peekFirst() (O(1))
  * isEmpty() -> calls isEmpty() (O(1))
  * Both enqueue and dequeue operate in O(1) time without array shifting.
