ACTIVITY 1: DSALinkedList (Doubly-Linked, Double-Ended)
- Node class: DSAListNode with value, next, and prev references.
- List class: DSALinkedList maintains both head and tail pointers.
- Operations:
  * insertFirst(value): O(1) time
  * insertLast(value): O(1) time
  * peekFirst(): O(1) time
  * peekLast(): O(1) time
  * removeFirst(): O(1) time
  * removeLast(): O(1) time
- Edge cases handled:
  * Empty list checks (raises IndexError on remove/peek)
  * Single-item list (updating both head and tail to None on remove)
  * Multi-item list (updating adjacent prev/next pointers)


ACTIVITY 2: DSAStack & DSAQueue using DSALinkedList
- DSAStack:
  * push(value) -> insertFirst(value) (O(1))
  * pop() -> removeFirst() (O(1))
  * top() -> peekFirst() (O(1))
  * isEmpty() -> list.isEmpty() (O(1))
- DSAQueue:
  * enqueue(value) -> insertLast(value) (O(1))
  * dequeue() -> removeFirst() (O(1))
  * peek() -> peekFirst() (O(1))
  * isEmpty() -> list.isEmpty() (O(1))
  * Replaces array shuffling (O(N)) and circular modulo math with natural O(1) node pointer operations.
